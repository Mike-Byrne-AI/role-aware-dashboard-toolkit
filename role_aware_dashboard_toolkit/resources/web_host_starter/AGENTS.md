# Working on this generated web host

Read README.md and inspect the installed toolkit with
`python -m role_aware_dashboard_toolkit inspect`; consult `guide web` and
`guide workflows` for relevant contracts. The files here are editable host code.

Keep runtime data, identity keys, tokens, credentials and verification receipts
outside this source directory. Do not add a demo bypass or derive authority from
hidden buttons, submitted roles or browser state. Preserve live authorization,
record scope, shared freeze, revision checks and record/history atomicity.

Use synthetic temporary storage for tests. Verify actual saved state as well as
responses and browser presentation, including denied actions and restart.
Do not claim hosted authentication, recovery or deployment acceptance from a
local test. Obtain the user's direction before changing their live storage.
