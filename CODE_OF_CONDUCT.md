# Code of Conduct

Role-Aware Dashboard Toolkit expects respectful, professional collaboration in
all contribution channels.

## Expected behavior

- Be constructive and specific in technical feedback.
- Focus criticism on code and decisions, not people.
- Respect maintainer review boundaries and project scope.
- Protect confidential information and respect others' privacy.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Repeated hostile or disruptive communication.
- Sharing sensitive or private material without permission.

## Reporting

A monitored conduct-reporting contact must be published before public
contribution channels open. This local candidate does not yet provide one.
Do not post confidential concerns or identifying information in public issues.

Pre-OSS release state remains blocked on `oss_public_coordinates` and
`security_intake_contact` until real public project URLs and a monitored public
security reporting contact are documented. See [SECURITY.md](SECURITY.md) for
the current security-reporting policy.
